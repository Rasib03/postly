# 🚀 Postly

**Postly** is a cross-platform mobile application built with Flutter that transforms trending tech news into ready-to-publish LinkedIn posts powered by Google's Gemini AI.

---

## ✨ Features

- 📰 **Automated News Fetching:** Curates trending tech topics from sources like TechCrunch and Hacker News.
- 🤖 **AI Draft Generation:** Uses Google Gemini AI to turn news stories into engaging LinkedIn hooks and posts.
- 🔒 **LinkedIn OAuth 2.0 Integration:** Secure sign-in and direct publishing using official LinkedIn APIs.
- 🎯 **Customized Feed Preferences:** Tailors suggested topics based on user interests (Flutter, AI, Web, SaaS).
- ✏️ **Review & Refine Editor:** Edit drafts manually or use quick AI actions to refine post tone and length.

---

## 🛠️ Tech Stack

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **Architecture:** Getx / MVVM
- **Authentication:** LinkedIn OAuth 2.0 (`flutter_web_auth_2`)
- **AI Engine:** Google Gemini API
- **UI Design:** Material 3 with custom iOS-inspired styling
